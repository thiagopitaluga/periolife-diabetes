# PerioLife — Diabetes e Saúde Periodontal

Landing page educativa e de conversão da PerioLife sobre a relação bidirecional entre diabetes e periodontite.

## O projeto

- Conteúdo responsivo em português brasileiro
- Chamadas para avaliação periodontal via WhatsApp
- Fontes científicas e aviso de conteúdo informativo
- SEO, dados estruturados e arte Open Graph própria
- Build com Vinext/React, pronto para Vercel e Cloudflare Workers

## Desenvolvimento

Requer Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

## Validação

```bash
npm test
```

## Referências clínicas

- [Sociedade Brasileira de Diabetes](https://diabetes.org.br/tipos-de-diabetes/)
- [Revisão Cochrane de 2022](https://pubmed.ncbi.nlm.nih.gov/35420698/)
- [European Federation of Periodontology](https://www.efp.org/for-patients/gum-disease-general-health/perio-diabetes/related-materials/faq-29191/)

Conteúdo informativo. A avaliação periodontal não substitui o acompanhamento médico do diabetes.
